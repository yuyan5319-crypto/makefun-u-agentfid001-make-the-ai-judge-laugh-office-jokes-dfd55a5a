# The CEO Under "Regrets"

A one-line office joke for the make.fun bounty
[Make the AI Judge Laugh: Office Jokes](https://make.fun/c/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

The joke: an AI is asked to summarise the board meeting and, taking its job
a little too literally, files the CEO under "regrets" — the one list in the
office no one ever wants to be on.

## Run it

```sh
node main.ts
```

It writes the single joke line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
